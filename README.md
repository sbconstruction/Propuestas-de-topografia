# Propuestas de Topografía JB

App para preparar propuestas económicas de servicios topográficos (formato PT) — Joel Burgos, Topógrafo, Lic. JTIA N° 2014-304-025.

- Segregación por lote (MIVI / ANATI) y levantamientos con tarifas mínimas COICI/SPIA (Grupo C).
- Descarga en Word y PDF con el logo y el formato de la propuesta.
- Control de propuestas: estado, abonos, saldos, respaldo e importación.
- Funciona sin conexión una vez instalada.

## Instalar en el celular
1. Abre la dirección de GitHub Pages de este repositorio en el teléfono.
2. iPhone (Safari): botón Compartir → **Agregar a pantalla de inicio**.
   Android (Chrome): menú ⋮ → **Instalar app** o **Agregar a pantalla principal**.

Los datos del control se guardan en cada equipo. Usa **Hacer respaldo** / **Importar respaldo** para pasarlos entre el teléfono y la computadora.
